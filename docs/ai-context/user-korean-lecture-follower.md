사용자는 한국어로 대화하고, 강의 영상을 보면서 같은 결과가 나오는지 확인한다. 개발 용어보다 "어디를 눌러라, 이 파일이 어디 있다" 식의 구체적 안내를 선호한다. 강의와 다른 부분이 있으면 무엇이 다른지 표로 비교해 알려 달라는 흐름이었다.

**Why:** 강의 화면과 결과가 다르면 따라가기 어려워한다.
**How to apply:** 강의 화면과 다른 점은 먼저 비교해서 알리고, 설정/메뉴 위치는 화면 이름 그대로 안내한다. 답변은 한국어로 짧고 실행 가능하게.
