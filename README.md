# autoedit — 유튜브 1차 자동 편집기

## 실행 방법 3가지
| 방법 | 설명 |
|---|---|
| `ui.bat` | **웹 UI** (http://127.0.0.1:8766). 영상 올리기, 옵션, 단계별 실행, 로그, 결과 미리보기 |
| `watch.bat` | `inbox/` 폴더에 영상을 넣으면 자동 처리 -> `output/` |
| `run.bat 영상.mp4` | 영상 1개 직접 처리 (옵션은 `--help`) |

## 파이프라인 (6단계, 단계별 캐시)
1. **전사** (faster-whisper) — 단어 단위 타임스탬프 대본
2. **컷 편집** — `MIN_SILENCE`초 이상 무음을 `KEEP_SILENCE`초로 줄임, 필러워드(어/음…)·말더듬(반복어) 제거
3. **기획** (Claude) — 대본에서 설명 일러스트가 필요한 순간 + 회사/제품 로고를 띄울 순간 선정
4. **이미지 생성** — OpenAI `gpt-image-1`(키 있을 때) 또는 Claude SVG(플랫 벡터 + 핸드드로잉), 로고는 `로고/` 폴더 이미지 사용
5. **개인정보 탐지** — 화면 속 전화번호·주민번호·카드/계좌·이메일·주소 OCR 모자이크, (선택) 얼굴, (선택) 말로 읽은 번호 음소거
6. **최종 렌더** — 모자이크 + 일러스트/로고 오버레이 + 자막을 한 번에 인코딩 -> `output/<영상>_edited.mp4`, 검수용 `work/<영상>/report.json`

앞 단계 결과가 있으면 재사용하고 없으면 자동으로 먼저 실행합니다. 옵션을 바꿨다면 해당 단계를 "강제 재실행"하세요.

## 설정
`.env` (견본: `.env.example`) 또는 웹 UI 의 "설정(API 키)". 키가 없어도 해당 단계만 건너뛰고 나머지는 동작합니다.
일러스트 위치: 전체 화면 전환 / 중앙 카드 / 우측 카드. 로고는 `로고/` 폴더에 `오라클.png` 처럼 **브랜드 이름으로 파일명**을 지어 넣으세요.

## 한계 (꼭 검수하세요)
- 기본 OCR 은 숫자·영문에 강하고 한글(이름·주소)은 약합니다 -> 이름/지명은 `가릴 단어`로 지정
- Whisper 가 필러워드를 못 받아적으면 컷되지 않습니다
- 야외 영상처럼 배경소음이 크면 무음 기준을 자동 보정하지만, 필요하면 `무음 소리 기준(dB)`을 올리세요
- 이 PC 는 Windows 보안 정책이 GPU 라이브러리를 막아 음성 인식이 CPU 로 돌 수 있음 (느리면 `medium`)
- 자동 결과는 1차 편집본입니다. 업로드 전에 모자이크/음소거/일러스트 위치를 확인하세요
- 환경: Python 3.12 venv(`.venv`)
